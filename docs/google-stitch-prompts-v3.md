## 一、介绍页提示词

请为一个中文 Web 产品设计介绍页 UI，产品名叫“阿财”。

### 页面定位

这是整个产品的第一页，只承担品牌介绍、边界说明和引导开始的职责。

它不是表单页，不展示结果，不展示推荐股票，也不展示复杂筛选控件。

用户点击主按钮后，才会进入独立表单页。

这是一个独立页面，不是三步流程中的第一个长页面区块。

### 设计目标

请设计一个：
- 有品牌记忆点
- 有温度
- 边界清楚
- 愿意让用户点击开始

的中文产品介绍页。

### 页面气质

- 可信但不冷
- 俏皮但不幼
- 有品牌感，但不广告化
- 温暖、克制、现代

### 吉祥物要求

- 吉祥物是介绍页主视觉核心
- 允许较大面积呈现
- 但不要把整页做成“招财海报”或“毛绒玩偶海报”
- 不要叠加金元宝、K线、金币、暴涨箭头
- 不要重新设计新的猫形象

### 内容结构

请包含以下模块：

1. 顶部导航栏
2. 吉祥物主视觉
3. 很短的产品说明
4. 一个轻量的信任信息位
5. 主按钮
6. 风险提示

其中顶部导航栏要求：
- 左侧露出阿财品牌
- 右侧只有两个导航项：
  - 产品
  - 关于阿财
- 这是品牌导航，不是流程导航
- “关于阿财”必须跳转到独立页面
- 不要做成介绍页 / 关于阿财页 / 表单页 / 结果页的切换 tab

其中“轻量的信任信息位”要求：
- 不要做成 3 个并列说明模块
- 不再使用“候选筛选”“优先证据”“宁可拒答”这种三块式表达
- 改成一个更克制的单点信息
- 优先使用“已提供 x 次建议”这样的使用痕迹信息
- 这个信息位应放在吉祥物主视觉右侧，而不是放在吉祥物下方
- 这个信息位要贴近吉祥物，不要离得太远，避免像两块互不相关的信息
- 这个信息位更像贴在吉祥物旁边的标记，不要做成独立浮在一边的小卡片

主按钮文案可以类似：
- 优先使用“开始筛选”
- 开始看看
- 去填写条件

### 文案要求

- 所有用户可见文案必须为中文
- 文案克制、清楚、短
- 不使用荐股口吻
- 不使用收益承诺
- 首页说明文案应压缩成很短的一句，不要再写成长段说明
- 这句短说明应放在吉祥物主视觉下方
- 桌面端优先单行展示，不要轻易折成两行
- 不要在品牌名上方再加一行类似“聪明的橘猫，先帮你把条件理顺”的预热文案

### 布局要求

- 不使用“左侧品牌右侧表单”的旧结构
- 优先使用更像品牌介绍页的单屏或偏中轴布局
- 顶部需要有轻量导航栏，左侧露出阿财品牌，右侧为“产品”和“关于阿财”
- 吉祥物主视觉应成为首页首屏最主要的视觉中心
- 吉祥物主视觉在首屏中应居中摆放
- 首页不再要求单独放一句大主标题
- 首页中段不要再放 3 个并列说明卡片
- 首页说明文案应与吉祥物形成同一列关系，放在猫下面，而不是悬在整组内容上方
- “已提供 x 次建议”这类轻量信任信息应与吉祥物组成一组排版，并位于吉祥物右边
- 主按钮应上移，和“吉祥物 + 信任信息”形成更紧的首屏重心
- 主按钮要成为第一屏最强的行动焦点，尺寸要大气、克制、明确
- 主按钮长度应明显拉长，形成更强的横向压场感
- 首屏整组内容在视觉上应略微下沉，不要贴着导航栏下方开始排
- 吉祥物、短说明、主按钮之间的纵向间距要比常规产品页稍微更大一些
- 首页下半部分不要留出过于空旷的大块留白，首屏重心要更稳地落在中下区域
- 第一屏就要完成表达，不要拉成长篇营销页
- 页面内不要出现可直接切换到表单页或结果页的 tab 导航
- 不要通过向下滚动继续看到表单页或结果页内容
- 如果需要流程感，只能做轻量步骤提示，不能做可点击切换
- 风险提示应以小字放在页面最下方，不要抢第一屏重心
- “产品”和“关于阿财”这两个导航项应更像品牌站导航，不要做成高亮胶囊式流程 tab

### 视觉要求

- 背景以米白、暖白、浅纸张色为主
- 文字以深墨灰为主
- 橘色作为品牌强调
- 可以少量使用青绿色平衡
- 不要红绿大对比
- 不要黑金暴富风

### 必须避免

- 首页直接展示表单
- 首页直接展示结果
- 左右硬拆的模板感落地页
- 传统金融广告站感
- 老式本土财经门户感
- 满屏猫咪重复元素
- 把介绍页做成三页合一的第一屏
- 做成“继续往下滑就是表单页”的长滚动首页
- 用 3 个卡片同时讲“候选筛选 / 优先证据 / 宁可拒答”
- 在吉祥物上方或下方再塞一条很重的大标题
- 把风险提示做成正文级大字放在按钮附近
- 在首页顶部做“第 1 步”之类的强提示标题
- 把“产品”和“关于阿财”做成介绍页 / 关于阿财页 / 表单页 / 结果页的切换器

### 交付目标

请输出一个介绍页 UI：
- 让用户记住阿财
- 让用户理解产品边界
- 让用户愿意点击进入表单页

## 二、表单页提示词

请为一个中文 Web 产品设计独立表单页 UI，产品名叫“阿财”。

### 页面定位

这是介绍页之后的第二页，只承担“填写条件并开始分析”的职责。

它不是品牌介绍页，也不是结果页。

它必须是独立表单页，而不是介绍页下方接着出现的第二屏。

### 设计目标

请设计一个：
- 干净
- 易扫描
- 中文友好
- 选择效率高

的独立表单页。

### 页面气质

- 更像友好的筛选工作区
- 比介绍页更克制
- 比结果页更轻
- 重点是填写效率，不是品牌展示

### 吉祥物要求

- 吉祥物只能轻量承接品牌
- 更适合以小头像方式贴在表单主标题旁边
- 不要占据首屏主体
- 不要做成海报
- 不要重复出现很多次
- 不要另外配一段解释吉祥物存在的说明文案

### 页面结构

请包含以下模块：

1. 表单主标题
- 优先使用“填写你的筛选条件”
- 主标题应直接放在表单容器顶部
- 吉祥物小头像应放在标题左侧，作为轻量品牌露出
- 不要再额外设计一块独立页头来写“第二页”或另一句大标题

2. 简短引导说明
- 一句话即可

3. 条件填写表单
- 字段全部使用中文
- 尽量使用选择式交互，不要让用户大量自由输入
- 预算：数字输入
- 目标收益参考：数字输入
- 风险承受能力：单选
- 投资周期：单选
- 是否接受高波动：二选一
- 方向偏好：多选，支持搜索选择
- 风格偏好：单选

4. 已选方向标签区

5. 主按钮
- 例如“开始分析”

6. 次入口
- 例如“返回介绍页”

### 页面流程要求

- 用户点击“开始分析”后，进入独立结果页
- 页面上可以有“返回介绍页”入口，但不应提供直接切换到结果页的 tab
- 不要在同一页面中提前展示结果页主体内容
- 不要把介绍页、表单页、结果页做成步骤条下的同屏切换面板

### 交互要求

- 用户能选就不让用户写
- 中文字段要清楚可读，不要又小又淡
- 方向偏好不能无序铺满全屏
- 要有搜索后选择的感觉
- 已选内容应清楚显示为中文标签

### 视觉要求

- 不要沿用介绍页的大海报布局
- 不要左右强拆成模板式首页
- 不要大白卡 + 厚阴影 + 渐变按钮的通用模板感
- 依靠排版、留白、边界和控件组织建立高级感
- 背景保持安静
- 品牌色少量点缀即可

### 文案要求

- 所有用户可见文案都必须使用中文
- 不暴露英文字段名
- 不使用金融营销语言
- 不要出现“第二页 · 填写条件”这类步骤式眉题
- 不要再写一条独立的大句子去重复表单页目标

### 必须避免

- 表单页继续做大主视觉吉祥物
- 太像后台配置页
- 太像老式金融筛选器
- 太像介绍页的延续海报
- 信息拥挤
- 表单页下半部分直接接结果预览
- 做成左边表单右边结果预览的一体式长页面
- 顶部三个 tab 一点就切到介绍页或结果页

### 交付目标

请输出一个中文独立表单页 UI：
- 让用户填写起来顺手
- 让中文字段清楚可读
- 让选择过程有秩序
- 与介绍页同品牌，但明显更像筛选工作区

## 三、结果页提示词

请为一个中文 Web 产品设计结果页 UI，产品名叫“阿财”。

### 页面定位

这是介绍页和表单页之后的第三页，用户已经填写完条件并提交，现在进入结果页查看分析结果。

这是独立结果页，不是表单页提交后的同页展开区域。

### 设计目标

请设计一个：
- 专业但友好
- 理性、克制
- 信息和证据优先

的结果页。

### 页面气质

- 更像工作台
- 更像分析页面
- 友好但不卖萌
- 与介绍页同品牌，但明显更理性

### 页面支持的结果状态

需要统一承载以下四种状态：
- 信息不足
- 目标偏高或条件冲突
- 暂无明确候选
- 已有候选

说明：
- 这里的四种状态指同一个结果页模板需要支持的四种页面状态
- 不要把这四种状态设计成 4 个并列 tab 让用户自己切换
- 本次交付可以重点展示“已有候选”状态，但版式要能自然扩展到其他三种状态

### 页面结构

请包含以下模块：

1. 顶部结果状态区
2. 用户已选条件摘要区
3. 主结果区
4. 总体说明区
5. 每只股票模块内的来源证据展开区
6. “重新输入一次”按钮
7. 风险声明

### 内容要求

#### 用户已选条件摘要区

要清楚回显：
- 预算
- 目标收益参考
- 风险承受能力
- 投资周期
- 是否接受高波动
- 方向偏好
- 风格偏好

#### 主结果区

- 若已有候选：展示候选股票模块列表
- 若暂无明确候选或条件冲突：展示原因分析和下一步建议

当存在多只候选股票时，必须按“每只股票一个独立模块”的方式设计。

每只股票模块都必须包含：
- 股票名称
- 股票代码
- 所属行业
- 入选原因
- 核心依据摘要
- 主要风险
- 不确定性说明
- 该股票自己的置信度
- 该股票自己的主要依据来源
- 该股票自己的来源证据展开入口或来源证据摘要

#### 来源证据展开区

- 非常重要
- 要展示来源级别、站点名、标题、日期、简短摘要
- 组织方式可参考 Perplexity 的“答案 + 来源”关系
- 但必须更适合中文产品阅读习惯
- 当存在多只候选股票时，来源证据必须挂在对应股票模块下，不能做一个全局共享证据区

### 吉祥物要求

- 只能小范围出现
- 可以出现在顶部状态旁、空状态、证据不足提示区、加载陪伴区
- 不要出现在候选卡片背景
- 不要出现在来源证据主阅读区
- 不要在每个模块都重复一次
- 不要占据大面积 hero 位置

### 视觉要求

- 延续品牌系统，但显著降低装饰性
- 使用更多中性色和留白
- 橘色只做少量品牌强调
- 不要大面积插画背景
- 不要红绿强对比
- 不要黑金暴富风
- 不要股票推荐海报风

### 文案要求

- 所有用户可见文案必须使用中文
- 不暴露英文字段名
- 不使用荐股口吻
- 不使用夸张金融营销语言

### 版式要求

- 结果页更像信息工作台，不像品牌海报
- 阅读路径要像“先看结果，再看理由，再看证据”
- 候选区和证据区要有明确层次
- “重新输入一次”按钮要清楚可见
- 当有多只候选股票时，每只股票都要形成清楚独立的内容块，不能共用一个置信度或一个来源模块
- 不要让用户通过顶部 tab 在介绍页、表单页、结果页之间任意跳转
- 不要把结果页做成单页长滚动中的第三段
- 如果有流程提示，只能用于说明当前在第几步，不能代替页面导航

### 必须避免

- 结果页太萌
- 结果页像介绍页海报延续页
- 满屏猫咪元素
- 证据区被弱化
- 信息层级混乱
- 多个股票共用一个置信度
- 多个股票共用一个来源证据区
- 太像东方财富或 i问财 的旧式金融页面
- 四种结果状态做成四个并列 tab
- 表单提交后仍停留在同一页面，只是局部展开结果区

### 交付目标

请输出一个中文 Web 产品结果页 UI：
- 专业但友好
- 信息和证据优先
- 能承载四种结果状态
- 能清楚回显用户已选条件
- 有明确的“重新输入一次”按钮
- 与介绍页、表单页同品牌，但明显更理性、更克制
